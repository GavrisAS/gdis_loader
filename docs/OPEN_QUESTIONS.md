# Открытые вопросы заказчику

Открыты только девять предметных вопросов из `Вопросы_v2.xlsx`. Пока ответа нет,
не вводить эвристики и не записывать значения, которые зависят от решения.

1. **Точный день MONTH-only даты.** Как определить календарный день для даты
   запуска/ГТМ, когда источник содержит только месяц или год? Сохранять
   `PartialDate`; target `Дата запуска` и зависящие от неё расчеты оставлять
   пустыми, если правило требует точного дня.
2. **Роль ПВР, КЛК и иных ГТМ в lifecycle.** Какие мероприятия начинают новую
   историю/дату запуска? Пока не считать их границей автоматически.
3. **Последовательные ЗБС и аналоги.** Как именовать несколько этапов одного
   типа (например, `ЗБС2`, `ЗБС3`)? До ответа не синтезировать suffix.
4. **Эквивалентность пластов.** Какие обозначения пластов семантически
   эквивалентны? Пока допустима только косметическая нормализация; при
   неравенстве normalized labels не выполнять fuzzy match.
5. **Смысл `ГС`.** Как трактовать `ГС` при идентификации скважины и lifecycle?
   Сохранять raw label и не схлопывать его в другую lifecycle identity без
   однозначного правила.
6. **Продолжительность без ИД/КВД без истории.** Какое значение использовать,
   если в текущей lifecycle-истории еще ни разу не было соответствующего ИД или
   КВД? Пока target остается пустым.
7. **Работающий день для дебита.** Какие значения/условия суточного рапорта
   считать работающим днем при среднем дебите? Пока `Дебит` не рассчитывается.
8. **Недостаточные исходные данные для qualitative flags.** Как трактовать
   missing/invalid inputs в qualitative признаках? До ответа использовать
   conservative tri-state: доказанное TRUE — `Да`; доказанное FALSE только при
   наличии всех необходимых inputs — `Нет`; иначе blank + diagnostic.
9. **Актуальная строка `Статус исследований_2026.xlsx`.** Как выбрать
   историческую строку для `Проблемы ГДМ`, включая допустимые типы исследований
   и fallback, когда Delta последней строки invalid/missing? Reader сохраняет
   строки и candidate audit, target остается пустым.

Ответы на предыдущие 22 вопроса см. в
[`CUSTOMER_DECISIONS.md`](CUSTOMER_DECISIONS.md). Не добавлять эти прежние темы
обратно в блокеры.

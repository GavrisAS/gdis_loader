# Наблюдения о текущих исходниках

Здесь зафиксирована структура входных файлов для readers. Подтвержденные правила заказчика находятся отдельно в [`CUSTOMER_DECISIONS.md`](CUSTOMER_DECISIONS.md). Презентация из комплекта не является источником бизнес-правил.

## Калькулятор `GDIS_Rating_Calculator_FIXED.xlsx`

- Target лист `Данные`; заголовки в строке 6, первая запись в строке 7.
- 26 столбцов A:Z; Excel Table `tblData`; исходный ref `A6:Z106`.
- Writer меняет только XML этого листа и table XML.

## Фонд `Фонд 2026 на 01.08.2026.xlsx`

- В актуальном примере датированный лист `01.08.2026`, дата фонда в `C1`.
- Источник строк фонда — группы `C`, `D`, `G`, `H`; `J` с освоением/ожиданием не включается по исходному README.
- Текущая схема матричная: количество группы и список скважин расположены на соседних строках.
- Встречается `153 162` без запятой; контрольное число и ГДИ поддерживают разделение на два номера с INFO provenance.
- Номер normalization удаляет только ведущие нули числовой части; suffix не схлопывается.

## `База по скважинам.xlsx`

- Двухстрочный header. Target лист `БЛУ`; модели также знают `ХЛУ -> Хадырьяхинское` и `ПЛУ -> Пырейное`.
- Базовые поля: куст, скважина, ВНС, пласт, информация, заканчивание, примечание.
- Блоки ГТМ имеют повторяемый шаблон из шести столбцов `ГТМn`, дата, пласт, отчет, заканчивание, примечание; reader находит все блоки по header.
- Значения raw сохраняются вместе с адресом ячейки. Hyperlink target не используется как значение.
- Дата в Excel может быть точностью день, месяц/год (`M.YYYY`) или год. Number format учитывается для значений вроде `7.202` с `0.0000`.

## Сводная таблица ГДИ

- Reader ищет столбцы по заголовкам, включая `Вид исследования`, `Дата`, `Глубина записи, м`, `Выход на РФП (да/нет)` и `Достоверность согласно ЛНД`.
- Текст вида исследования хранится как raw value; классификация в real-data audit агрегируется без записи полного production списка строк.
- GDI type audit текущего scope: см. [`GDI_KIND_AUDIT.md`](GDI_KIND_AUDIT.md).

## База ЛХА

- Рабочий лист `БД Сибнефтегаз`; reader использует поле, номер, пласт, timestamp, Cl и ВГФ.
- Для одной метрики timestamp collapses в максимальное валидное numeric значение. 0 считается числом, missing и invalid остаются отдельными provenance/diagnostics.
- Suffixless LHA history подключается к suffix lifecycle только при однозначном совпадении поля, пласта и времени.

## Суточный рапорт

- Схема `Добыча телеметрия` проверяется, дневные значения остаются зарезервированными для расчета после уточнения определения работающего дня.
- Средний дебит не вычисляется до ответа заказчика.

## Реальные данные и тестовые fixtures

Реальные файлы в `data/` игнорируются Git. Интеграционные тесты пропускаются, если их нет; CI использует небольшие синтетические fixtures без производственных значений.

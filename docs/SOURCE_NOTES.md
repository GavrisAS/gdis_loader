## Фонд 2026 на 01.08.2026.xlsx

Актуальный тестовый лист: `01.08.2026`. В новых файлах следует выбирать наиболее поздний лист с именем формата `DD.MM.YYYY`, исключая листы с префиксом `RSPN`, если схема остается той же.

Дата фонда находится в `C1`.

Таблица фонда является матричной, а не нормализованной: строки с количеством чередуются со строками, содержащими списки номеров скважин.

Для эксплуатационного фонда в текущей схеме видны группы:

- `C` — дающие газ;
- `D` — остановленные в отчетном месяце;
- `G` — бездействующие текущего года;
- `H` — бездействующие прошлых лет;
- `J` — в освоении/ожидании освоения. По исходному `README.txt` рейтингованию
  подлежит действующий + бездействующий фонд, поэтому J не входит в мастер-список
  и диагностируется как INFO `FUND_CATEGORY_J_IGNORED` с адресом ячейки J.

README исходных данных указывает, что рейтингованию подлежит эксплуатационный фонд: действующий + бездействующий.

## База ЛХА_Итог!.xlsm

Используемый лист: `БД Сибнефтегаз`.

Подтвержденные заголовки:

- `Месторождение`
- `Номер скважины`
- `Пласт`
- `Дата и время исследования`
- `Данные ЛХА, CL-, мг/дм3`
- `ВГФ, г/м3`

В текущем файле это соответственно колонки C, D, E, G, Z, BC, но код должен по возможности опираться на заголовки.

В номере скважины в этой базе могут отсутствовать обозначения ЗБС/ГС. Для корректной связи необходимо учитывать номер, дату и пласт.

В просмотренной истории ГДИ реально встречаются `ЗБС`, `МЗС`, `ГС`, формы
`ЗБС2`/`ЗБС_МГРП`/`ЗБС(ГС...)`, а также суффикс `R`. Первые явно подтверждённые
варианты нормализуются по отдельным правилам; значение `R` автоматически не
удаляется. В ЛХА встречаются пластовые записи `ПК₁`, `ПК19(2)` и близкие
косметические варианты.

Значения могут содержать Excel errors (`#DIV/0!` и т. п.) и должны корректно считаться missing/invalid, а не падать.

## 07.2026 Cуточный рапорт БГП_полный.xlsm

README указывает источник дебита: лист `Добыча телеметрия`.

Структура текущего листа:

- `A1` — ГСК;
- `B1` — `СКВ.`;
- далее столбцы дней месяца 1..31;
- значения являются дневными дебитами/телеметрией;
- встречаются ошибки `#REF!`.

Как именно агрегировать дневные значения в одно целевое поле `Дебит`, в первой версии не предполагать без решения заказчика.

В `БД Сибнефтегаз` XML dimension может быть `A1:BT1048576`, хотя полезные
идентификационные строки заканчиваются значительно раньше. Reader использует
ограничение по серии пустых identity-строк, а не проходит миллион строк
только из-за форматирования/формул.

## Правило идентификации из исходного README

Номер скважины нельзя рассматривать в отрыве от времени и пласта. Одна скважина могла последовательно менять обозначение (например, ЗБС/ПВЛГ) и объект. Для ЛХА особенно важно не связать измерение с прежним пластом той же физической скважины.

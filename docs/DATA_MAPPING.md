# Маппинг листа `Данные`

## Scope

`validate` обнаруживает поля по строкам текущего фонда, нормализует canonical
названия и показывает покрытие в остальных sources. `update` требует одно явно
выбранное поле и пишет только eligible rows этого поля. В книгу не добавляется
колонка месторождения. Подтвержденные правила и девять unresolved decisions
описаны в [`CUSTOMER_DECISIONS.md`](CUSTOMER_DECISIONS.md) и
[`OPEN_QUESTIONS.md`](OPEN_QUESTIONS.md).

Eligible состояния: `дающие`, `дающие газ`, `остановленные в отчетном
месяце/периоде`. Первые два записываются как `Дающие газ`, остановленные — как
`Остановленные в отчетном периоде`. Остальные категории не попадают в target.
Для regression на текущем фонде Берегового ожидаются 109 строк до eligibility,
78 eligible, 31 исключенная и 78 строк в `Данные`.

## Целевые поля

| Поле `Данные` | Статус | Источник / правило |
|---|---|---|
| Скважина | заполняется | Однозначно сопоставленная актуальная lifecycle identity. Root без suffix может быть привязан к этапу только через поле, пласт, точную дату и историю. |
| Пласт | заполняется | Raw пласт выбранной текущей GDI записи; equivalence не выводить fuzzy-сопоставлением. |
| Состояние | заполняется | Нормализованная категория eligible фонда. |
| Дата запуска | условно | Дата начала текущего этапа; записывать только при precision DAY. MONTH/YEAR остаются пустыми с provenance. |
| Количество ГДИ | условно | Валидные ID/ID_KVD/KVD текущей истории после запуска. ID_KVD считается одной записью. Partial-date same-window ambiguity — blank. |
| Глубинные датчики | условно | Глубина записи последнего valid GDI: `>0` — Да, `0` — Нет, missing/invalid — blank. Не условие валидности GDI. |
| Расходомер | пусто / migration | Исключить в будущей структурной миграции; сейчас не менять workbook. |
| ГТМ | временно заполняется | `Нет` до появления плана работ. |
| Недостаточно ГДИС | условно | 0–1 valid GDI после запуска — Да, 2+ — Нет. При неполной дате использовать bounds; если threshold зависит от порядка — blank. |
| Снижение продуктивности | условно | Последние два валидных numeric `a` текущей истории; current > previous — Да, иначе Нет. Не хватает двух — blank. |
| Рост хлора | условно | Cl current > 2000 и прирост > 1000 мг/дм3 — Да, иначе Нет. Не хватает двух numeric точек — blank. |
| Cl текущий / предыдущий | заполняется | Точки ЛХА текущей lifecycle истории по timestamp. Дубликаты timestamp для одной метрики схлопываются к максимальному valid numeric значению. |
| Проблемы ГДМ | пусто / blocker v2 №9 | Reader формирует per-row candidates `abs(Delta)>5`; current-row aggregation пока не определена. |
| ЛНД | условно | Да при reliability `Низкая` или RFP `нет`; Нет только если оба распознаны и условия ложны; иначе blank. |
| Последний АДД / Не проведен АДД | пусто / migration | Удалить при отдельной структурной миграции; сейчас не менять workbook. |
| Продолжительность без ГДИ | условно | От последнего valid GDI; если его не было — от точной DAY launch date. `(calculation_date - source_date).days / 365`, без скрытого округления. |
| Удельное количество ГДИ | условно | Если count > 0 и launch DAY: `((calculation_date-launch_date).days/365)/count`. При count=0 оставить blank; future formulas должны использовать μi=0. |
| ВГФ текущий / предыдущий | заполняется | Та же lifecycle-safe LHA selection и duplicate maximum policy, что для Cl. |
| Продолжительность без ИД | условно | От последнего ID или ID_KVD; без такой истории blank до ответа v2 №6. |
| Продолжительность без КВД | условно | От последнего KVD или ID_KVD; без такой истории blank до ответа v2 №6. |
| Техническая возможность | пусто / migration | Исключить при отдельной структурной миграции; сейчас не менять workbook. |
| Дебит | пусто / blocker v2 №7 | Среднее по работающим дням; definition дня пока нет. |
| Manual μ | пусто | Ручное поле, автоматом не рассчитывать. |

## Matching и provenance

`base_well_id` служит физическим ключом lineage, а `target_well_id` сохраняет
suffix. Для suffixless GDI/LHA/GDM после lifecycle boundary требуется точная
однозначная assignment по field + root + date interval + normalized plast.
Same-month partial date, unresolved plast equivalence и неизвестные GTM stage
оставляют запись ambiguous.

JSON report содержит provenance cell inputs каждого вычисленного derived field.
Diagnostics связывают файл, лист и ячейки исходных workbook. Реальные строки и
выгрузки не помещать в документацию/обычные логи.

# Маппинг листа `Данные` — состояние первой версии

Статусы:

- `READY` — источник и правило достаточно определены для реализации;
- `CONDITIONAL` — можно заполнять только после однозначного well/plast match;
- `BLOCKED` — требуется уточнение бизнес-правила/источника.

| Поле | Статус | Источник / комментарий |
|---|---|---|
| Скважина | CONDITIONAL | Фонд + история ГДИ. Нужен консервативный resolver актуального обозначения по base well, пласту и последней релевантной дате. Неоднозначные случаи не угадывать. |
| Пласт | CONDITIONAL | Последняя однозначно сопоставленная запись ГДИ для актуальной конфигурации. |
| Состояние | BLOCKED | Фонд содержит действующий/остановленный/бездействующий категории, но точное преобразование в словарь калькулятора (`В работе`, `В бездействии` и др.) нужно подтвердить. |
| Дата запуска | BLOCKED | Не определен надежный текущий источник и правило: первичный ввод или запуск после ГТМ/ЗБС. |
| Количество ГДИ | BLOCKED | Не подтверждено, какие виды исследований считаются и с какой даты (весь период / после ГТМ/ЗБС). |
| Глубинные датчики | BLOCKED | Актуальный источник не определен. |
| Расходомер | BLOCKED | Актуальный источник не определен. |
| ГТМ | BLOCKED | Есть фактическая дата ГТМ в ГДИ, но критерий включает также планируемые мероприятия; нужен источник/окно времени. |
| Недостаточно ГДИС | BLOCKED | Требует утвержденного правила количества исследований и учета оборудования. |
| Снижение продуктивности | BLOCKED | Нужен критерий/источник экспертного или расчетного признака. |
| Рост хлора | BLOCKED | Есть история Cl, но не утверждено правило роста/порог/окно сравнения. |
| Cl текущий | CONDITIONAL | Последняя валидная запись `БД Сибнефтегаз` для однозначно сопоставленной скважины-пласта. |
| Cl предыдущий | CONDITIONAL | Предыдущая валидная запись той же актуальной скважины-пласта. |
| Проблемы ГДМ | BLOCKED | Экспертный список; источник не приложен. |
| ЛНД | BLOCKED | В ГДИ есть РФП и достоверность, но требуется нормализованное правило перевода множества текстовых категорий в Да/Нет. |
| Последний АДД | BLOCKED | Источник не определен. |
| Не проведен АДД | BLOCKED | Зависит от источника и правила скользящего года. |
| Продолжительность без ГДИ | BLOCKED | Нужны утвержденные состав ГДИ и дата отсечения. |
| Удельное количество ГДИ | BLOCKED | Зависит от даты запуска и определения количества ГДИ. |
| ВГФ текущий | CONDITIONAL | Последняя валидная запись `БД Сибнефтегаз` для однозначно сопоставленной скважины-пласта. |
| ВГФ предыдущий | CONDITIONAL | Предыдущая валидная запись той же актуальной скважины-пласта. |
| Продолжительность без ИД | BLOCKED | Нужна классификация значений `Вид исследования` и дата отсечения. |
| Продолжительность без КВД | BLOCKED | Нужна классификация значений `Вид исследования` и дата отсечения. |
| Техническая возможность | BLOCKED | Современный источник не определен. |
| Дебит | BLOCKED | Суточные значения есть; не утверждено правило агрегации в одно значение. |
| Manual μ | BLOCKED | Ручное поле; загрузчик первой версии не должен его придумывать. |

## Минимальный полезный результат v0.1

Первая версия должна прежде всего надежно построить мастер-список фонда и слой идентификации. После однозначного сопоставления разрешено записывать `Скважина`, `Пласт`, `Cl текущий`, `Cl предыдущий`, `ВГФ текущий`, `ВГФ предыдущий`.

Если статус `Состояние` не утвержден, строку все равно можно сформировать с пустым значением этого поля и диагностикой.

Наличие `BLOCKED`-полей не является ошибкой работы программы.

# Backlog: STRUCTURAL_CALCULATOR_MIGRATION

Отдельный этап после закрытия текущих бизнес-блокеров. Изменять структуру
калькулятора только после проверки влияния на его критерии, настройки и формулы.

Подтверждено заказчиком к исключению из калькулятора:

- целевые поля `Расходомер`, `Последний АДД`, `Не проведен АДД`,
  `Техническая возможность`;
- соответствующие columns, criteria/settings, formula references and layout
  dependencies across workbook sheets.

В этой итерации writer сохраняет столбцы физически, target cells остаются
пустыми, остальные листы и formulas не меняются.

Отдельно спроектировать поведение sigmoid при нулевом числе ГДИ:

- заказчик подтвердил `μi = 0`;
- скважина с нулем исследований не должна участвовать в sigmoid;
- не подменять это artificial zero в `Удельное количество ГДИ` target cell;
- при будущей миграции обновить calculation formulas and their capacity ranges.

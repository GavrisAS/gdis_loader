# Audit классификации видов ГДИ

Агрегаты текущего production source для месторождения Береговое. Полный список
production labels и строки workbook в Git не сохраняются.

| Класс | Старый classifier | Исправленный classifier |
|---|---:|---:|
| `ID` | 33 | 32 |
| `ID_KVD` | 866 | 867 |
| `KVD` | 695 | 702 |
| `EXCLUDED` | 209 | 209 |
| `UNKNOWN` | 29 | 22 |

Исправление ищет token `ИД` по границам, а устойчивый marker `КВД` — внутри
поясняющих labels. Классификация combined ID/KVD предшествует индивидуальной.
`Освоение`, отдельный `Pст` и отдельный `Pпл` исключаются. `UNKNOWN` сохраняется
в исходном representation, не считается valid GDI и остается в diagnostics.

Контрольные примеры после fix: `КВДгл`, `КВДстатика`, `КВД глубинн`,
`КВД при ПГИ`, `КВД+КСД`, `миниКВД`, `МЗС+миниКВД` -> `KVD`;
`ИД+КВДсм НКТ` и остальные combined variants -> `ID_KVD`. Отдельный token
`ИД` распознается без substring-совпадения в обычных словах. `КВУ`, `ПГИ`,
`длит.остановка` остаются `UNKNOWN`; `Освоение`, отдельные `Pст` и
`Замер Рпл` -> `EXCLUDED`.

Для бизнес-расчетов valid GDI определяется только как `ID`, `ID_KVD` или `KVD`;
depth не служит условием валидности. `ID_KVD` входит как одна запись в общий
count и одновременно в обе группы duration.
